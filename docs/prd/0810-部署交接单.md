## 二、为什么不是直接部署 `merge/lineage-0809`

**这是本次交接最重要的一条。**

`vercel --prod` 是**整树替换,不是合并** —— 谁最后跑,线上就 100% 是谁的分支。

我准备部署时探 `/api/version`,发现生产已经**不是**我建分支时那个 deployment 了
(期间换了两次:`dpl_GGNHppVs` → `dpl_2k6ubyFpMi` → `dpl_Gbidwc19`)。
直接部署我的分支,会让别人四个已上线的功能**从生产消失**:

```
ebb4601  feat(usage): 过期预留扫描——释放被占住的额度
5eb4f23  fix(publish): 抽屉还开着时显示 fan-out 结果
aabc491  fix(plan): 修复 hover 卡片乱码
be3153c  fix(plan): fan-out state 声明位置
```

所以改成**反向合并**:从线上那条分支起新分支,把我方 3 个合进去。零冲突。

- worktree 里可能缺 `.env.local` / `.vercel`,需从主仓库手动拷
