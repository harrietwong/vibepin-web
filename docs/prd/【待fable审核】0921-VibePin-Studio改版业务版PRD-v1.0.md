# VibePin Studio 改版业务版 PRD v1.0

> 更新日期：2026-09-21  
> 状态：业务需求确认稿  
> 适用范围：Studio、发布账号、排期计划、账号设置、数据洞察

## 1. 项目目标

### 1.1 当前问题

1. 创建内容、编辑文案、选择账号和排期分散在不同位置，操作路径过长。
2. AI 入口重复，用户容易误以为是两套功能。
3. 图片和视频使用了相同操作，视频卡会出现不适用的图片生成按钮。
4. 发布账号下拉列表会被卡片盖住，导致账号无法选择。
5. 排期计划默认显示过去日期，用户看不到最需要关注的今天和未来内容。
6. “已储存到这台装置”容易让用户误以为历史记录只保存在当前电脑。
7. 当前预览链接经常出现 Vercel 登录页，影响产品查看和验收。

### 1.2 改版目标

1. 用户在一个工作台内完成创建、编辑、选账号、排期和发布。
2. Website URL 成为 AI 创建内容的主要入口之一。
3. 复用现有 AI 功能，不再建立第二套 AI 流程。
4. 图片和视频显示各自适用的操作。
5. 排期计划默认只显示今天及未来。
6. 草稿和历史记录跟随 VibePin 登录账号，不跟随单台设备。

### 1.3 成功标准

| 项目 | 目标 |
|---|---:|
| 用户能够完成“创建 → 编辑 → 选账号 → 排期或发布”完整流程 | 100% 通过验收 |
| 视频卡错误显示图片生成按钮 | 0 次 |
| 发布账号列表被卡片遮挡 | 0 次 |
| 排期计划首次打开显示过去日期 | 0 次 |
| 用户已修改内容被 AI 自动覆盖 | 0 次 |
| 固定预览链接出现 Vercel 登录页 | 0 次 |
| 不同 VibePin 账号看到彼此的草稿或历史 | 0 次 |

## 2. 用户与核心流程

### 2.1 目标用户

1. 使用独立站商品页、文章页或落地页制作社媒内容的商家。
2. 批量制作 Pinterest 内容，并同步发布到 Instagram 或 Facebook 的创作者。
3. 已有图片或视频，希望快速补齐文案和排期的用户。
4. 需要管理多个发布账号和历史内容的运营人员。

### 2.2 核心流程

```text
用 AI 创建 / 上传媒体
→ 输入网址或选择媒体
→ 生成内容卡片
→ 编辑图片、视频和文案
→ 选择发布账号
→ 立即发布或排期
→ 在计划中查看
→ 在数据洞察中复盘
```

## 3. Studio 工作台

### 3.1 页面结构

| 区域 | 内容 |
|---|---|
| 左侧 | 全局导航 |
| 中间 | 创建入口、筛选和内容卡片 |
| 右侧 | 可收起的排期计划 |

### 3.2 卡片列数

| 页面宽度 | 默认列数 |
|---|---:|
| 大屏 | 4 列 |
| 普通桌面 | 3 列 |
| 小屏桌面或平板 | 2 列 |
| 手机 | 1 列 |

主区不再限制为最多两列。正在编辑的卡片可以变宽，其他卡片保持紧凑。

### 3.3 顶部字段与按钮

| 类型 | 名称 | 规则 |
|---|---|---|
| 搜索 | 搜索内容 | 可按标题、网址、画板或状态搜索 |
| 筛选 | 内容状态 | 全部 / 草稿 / 已排期 / 已发布 / 失败 |
| 筛选 | 发布平台 | 全部 / Pinterest / Instagram / Facebook |
| 按钮 | `用 AI 创建` | 打开现有 AI 创建功能 |
| 按钮 | `上传媒体` | 上传图片或视频 |
| 按钮 | `批量操作` | 选中内容后启用 |
| 按钮 | `历史记录` | 查看当前账号的历史内容 |
| 状态 | 已选择数量 | 显示已选卡片数 |
| 状态 | 保存状态 | 保存中 / 已保存 / 等待同步 |

### 3.4 页面规则

1. 大屏应充分利用宽度，避免卡片过宽或空白过多。
2. 手机端使用单列，主要按钮无需横向滚动。
3. 搜索、筛选、上传和 AI 创建入口始终容易找到。
4. 页面打开后不自动展开所有卡片。

## 4. AI 创建与 AI 文案

### 4.1 入口

| 入口 | 位置 | 打开后的内容 |
|---|---|---|
| `用 AI 创建` | Studio 顶部 | 空白 AI 创建页面，网址输入框自动选中 |
| `生成 AI 版本` | 图片卡 | 自动带入当前图片、网址和文案 |
| `重新生成图片` | 图片卡 | 自动带入上一次设置 |

以上入口使用同一套 AI 功能、生成记录和失败恢复方式。

### 4.2 根据网址创建内容

```text
输入 Website URL
→ 点击分析网址
→ 查看网页摘要和可用图片
→ 选择主要图片和参考图片
→ 选择创作方向
→ 生成内容
→ 在卡片内继续编辑
```

系统可以判断网址类型，但不显示额外提示卡、阻断弹窗或外部设置引导。

### 4.3 图片生成字段

| 字段 | 必填 | 规则 |
|---|---:|---|
| Website URL | 否 | 保留用户原始输入 |
| 网页摘要 | 否 | 展示商品、主题或文章摘要 |
| 主要图片 | 是 | 决定需要保持的主体 |
| 补充图片 | 否 | 帮助保持主体一致 |
| 风格参考图 | 否 | 只影响风格，不改变主体 |
| 创作方向 | 是 | 用户可直接修改 |
| 风格、场景、构图、氛围 | 否 | 使用现有选项 |
| 生成数量 | 是 | 使用现有数量限制 |
| 图片比例 | 是 | 默认使用 Pinterest 推荐比例 |
| 结果差异度 | 否 | 控制多张结果的差异 |

### 4.4 图片生成按钮与状态

| 类型 | 名称 | 规则 |
|---|---|---|
| 按钮 | `分析网址` | 网址有效时启用 |
| 按钮 | `添加图片` | 添加主要或补充图片 |
| 按钮 | `添加参考图` | 添加风格参考图 |
| 按钮 | `生成方向` | 提供 3 个不同创作方向 |
| 按钮 | `生成` | 必填内容完整时启用 |
| 按钮 | `取消生成` | 仅在可以安全取消时显示 |
| 按钮 | `重试失败项` | 只重新生成失败内容 |
| 状态 | 分析中 / 可继续 / 部分成功 / 失败 | 明确显示当前进度 |
| 状态 | 正在生成 X 项 | 显示总数、成功数和失败数 |

### 4.5 AI 文案字段

| 字段 | 规则 |
|---|---|
| 内容目的 | 推荐商品 / 促销 / 幕后内容 / 生活方式 / 知识内容 |
| 主题或商品 | 根据网址、图片或当前卡片自动带入 |
| 关键词 | 可选 |
| 行动引导 | 可选 |
| 语言 | 默认使用账号设置语言 |
| 发布平台 | Pinterest / Instagram / Facebook |
| 处理已有文案 | 只填空白字段 / 提供替换建议 |

### 4.6 AI 文案按钮

| 按钮 | 规则 |
|---|---|
| `生成文案` | 信息完整时启用 |
| `重新生成` | 保留当前输入，生成新版本 |
| `应用此字段` | 只替换当前字段 |
| `应用全部建议` | 先说明将替换哪些内容 |
| `保留当前内容` | 不使用本次建议 |

### 4.7 AI 业务规则

1. AI 必须保持商品颜色、结构、数量和主要外观。
2. 用户确认主要图片后，AI 不得自行改变商品主体。
3. 用户已经修改的字段不得被自动覆盖。
4. 生成多项内容时，先出现对应数量的等待卡片，再逐项显示结果。
5. 某一项失败时，已经成功的结果必须保留。
6. 文案生成失败时，用户仍可继续手动编辑。
7. AI 生成内容必须保留真实的 AI 生成标记。

## 5. 内容卡片

### 5.1 字段顺序

| 顺序 | 字段 |
|---:|---|
| 1 | 媒体预览和媒体状态 |
| 2 | AI 生成标记 |
| 3 | 媒体操作和比例选择 |
| 4 | Website URL |
| 5 | 标题 |
| 6 | 描述或 Instagram 文案 |
| 7 | Pinterest 画板 |
| 8 | 推荐关键词或标签 |
| 9 | 替代文字 |
| 10 | 发布账号 |
| 11 | 自定义时间 |
| 12 | 排期、发布和保存状态 |

### 5.2 图片卡与视频卡按钮

| 按钮 | 图片卡 | 视频卡 | 规则 |
|---|---:|---:|---|
| 选择 | 显示 | 显示 | 用于批量操作 |
| 更多 | 显示 | 显示 | 复制 / 移动 / 删除 |
| `更换媒体` | 显示 | 显示 | 更换前保留其他字段 |
| `选择比例` | 显示 | 显示 | 使用轻量选择器 |
| `生成 AI 版本` | 显示 | 不显示 | 打开现有 AI 创建功能 |
| `重新生成图片` | 显示 | 不显示 | 复用上一次图片设置 |
| `编辑封面` | 不显示 | 显示 | 放在视频主画面上 |
| `生成文案` | 显示 1 次 | 显示 1 次 | 每张卡只能有一个入口 |
| `排期` | 显示 | 显示 | 账号和时间完整后启用 |
| `发布` | 显示 | 显示 | 进入发布确认 |

### 5.3 图片与视频比例

| 类型 | 可选比例 |
|---|---|
| 图片 | 原始比例 / 2:3 / 1:1 / 4:5 / 9:16 |
| 视频 | 原始比例 / 9:16 / 2:3 / 1:1 / 16:9 |

1. 选择后立即更新预览，不修改原文件。
2. 用户可调整画面位置，或选择完整显示。
3. 视频改比例后，时长、声音、封面和文案保持不变。
4. 处理失败时保留原内容，并提供重试和恢复原始比例。

### 5.4 视频封面

| 类型 | 名称 | 规则 |
|---|---|---|
| 入口 | `编辑封面` | 桌面端鼠标移入或选中视频时显示；手机端持续显示 |
| 字段 | 当前画面 | 大图预览当前视频画面 |
| 字段 | 时间轴 | 可拖动选择画面 |
| 字段 | 推荐画面 | 显示推荐封面缩略图 |
| 按钮 | `使用当前画面` | 选择当前视频画面 |
| 按钮 | `上传封面` | 支持上传时显示 |
| 按钮 | `保存封面` | 保存当前选择 |
| 按钮 | `取消` | 放弃本次修改 |

视频下方不再显示独立封面小卡片、`Choose cover frame` 大按钮或第二个封面入口。

### 5.5 卡片规则

1. 系统识别为视频后，立即隐藏全部图片生成按钮。
2. 视频卡不得出现“生成 AI 版本”“重新生成图片”或相同含义的按钮。
3. 每张卡只保留一个“生成文案”入口。
4. 保存后的封面在卡片、排期计划、发布确认和最终发布结果中保持一致。
5. 收起卡片显示媒体、标题、账号、状态和主要按钮。
6. 展开卡片显示全部编辑字段。

### 5.6 保存与历史记录

| 状态 | 含义 |
|---|---|
| 保存中 | 正在保存修改 |
| 已保存 | 已成功保存到账户 |
| 等待同步 | 当前网络或保存失败，恢复后继续同步 |

页面不再显示“已储存到这台装置”。同一 VibePin 账号在另一台设备登录后，可以看到同一工作空间的草稿和历史；不同账号之间不得互相看到内容。

## 6. 发布账号与发布确认

### 6.1 字段

| 字段 | 规则 |
|---|---|
| Pinterest 发布目标 | 选择准确账号和画板 |
| Instagram 发布目标 | 选择准确账号 |
| Facebook 发布目标 | 选择准确主页 |
| 发布方式 | 立即发布 / 排期发布 |
| 排期时间 | 选择排期发布时必填 |
| 媒体预览 | 显示当前图片、视频和视频封面 |
| 文案预览 | 按平台显示最终文案 |
| 问题提示 | 分平台显示缺少的内容或权限 |

账号选项必须显示平台、头像、账号名称、用户名和连接状态，不能只显示模糊的品牌名。

### 6.2 按钮与状态

| 类型 | 名称 | 规则 |
|---|---|---|
| 按钮 | `选择发布账号` | 未选择账号时显示 |
| 按钮 | `立即发布` | 必填信息完整时启用 |
| 按钮 | `排期` | 账号和时间完整时启用 |
| 按钮 | `返回编辑` | 返回卡片并保留当前选择 |
| 按钮 | `重试失败平台` | 只重试失败的平台 |
| 状态 | 发布中 | 分平台显示进度 |
| 状态 | 部分成功 | 已成功的平台不重复发布 |
| 状态 | 结果确认中 | 先确认结果，不立即重复发布 |

### 6.3 账号下拉列表规则

1. 账号列表必须显示在所有卡片上方，不能被当前卡片或相邻卡片盖住。
2. 页面下方空间不足时，列表自动向上展开。
3. 账号较多时，列表内部可以滚动。
4. 页面滚动或卡片展开时，列表仍紧跟账号选择按钮。
5. 每个账号选项整行都可以点击。
6. 选中后立即显示平台、账号名称和用户名。
7. 没有账号时显示“连接账号”；连接失效时显示“重新连接”。
8. 系统不得自动选择默认账号或默认画板。

## 7. 右侧排期计划

### 7.1 展示方式

| 状态 | 规则 |
|---|---|
| 收起 | 页面右侧显示竖向“计划”入口，整块区域都可点击 |
| 侧栏 | 大屏与内容区并排，不遮挡卡片 |
| 抽屉 | 小屏从右侧打开 |
| 完整计划 | 查看未来日期、列表和未排期内容 |

### 7.2 字段与按钮

| 类型 | 名称 | 规则 |
|---|---|---|
| 字段 | 日期范围 | 显示开始和结束日期 |
| 字段 | 每日内容 | 显示日期、星期和已排数量 |
| 字段 | 排期内容 | 缩略图、标题、时间、平台和状态 |
| 字段 | 未排期数量 | 显示尚未排期的内容数 |
| 字段 | 本周已排数量 | 显示当前 7 天的内容数 |
| 字段 | 每天平均发布 | 标题区显示“每天平均发布 X 条” |
| 按钮 | `展开计划` | 点击右侧竖向区域打开 |
| 按钮 | `收起计划` | 收回右侧计划 |
| 按钮 | `未来 7 天` | 查看下一段未来日期 |
| 按钮 | `今天` | 回到今天开始的 7 天 |
| 按钮 | `查看过去` | 主动进入历史日期 |
| 按钮 | `回到今天` | 退出历史日期 |
| 按钮 | `完整打开` | 只放在右上角 |
| 按钮 | `收回侧栏` | 只放在完整计划右上角 |

底部不再显示“开启完整计划”按钮。

### 7.3 日期规则

1. 首次打开显示今天到未来第 6 天，共 7 天。
2. 不为了凑完整星期而显示今天以前的日期。
3. 今天列保留今天已经排期的内容。
4. 默认状态没有向过去翻页的按钮。
5. 用户点击“查看过去”后，才显示截至昨天的前 7 天。
6. 点击“回到今天”后，恢复今天开始的未来 7 天。
7. 日期按当前账号设置的时区计算。
8. 例如周日晚上 11 点打开，第一列仍为当天周日，后面显示周一至周六。

### 7.4 每天平均发布数量

| 类型 | 名称 | 规则 |
|---|---|---|
| 字段 | 每日发布目标 | 每天 1 至 10 条；套餐可限制上限 |
| 字段 | 排期时区 | 显示当前时区 |
| 状态 | 智能排期 | 可以随每日目标重新安排 |
| 状态 | 手动锁定 | 用户指定的时间不自动移动 |
| 按钮 | `每天平均发布 X 条` | 点击后选择数量 |
| 按钮 | `撤销` | 30 秒内撤销本次调整 |

用户选择新数量后立即生效，不增加保存按钮。系统只调整智能排期内容，不移动已经发布或手动锁定的内容。当天时间不足时，内容顺延到下一天，不得安排到过去。草稿不足时只保留空位，不创建虚假内容。

## 8. 社交账号设置

设置页面只保留一个“社交账号”入口，Pinterest、Instagram 和 Facebook 使用相同的账号卡结构。

### 8.1 字段与按钮

| 类型 | 名称 | 规则 |
|---|---|---|
| 搜索 | 搜索设置 | 搜索设置项 |
| 筛选 | 平台 | 全部 / Pinterest / Instagram / Facebook |
| 字段 | 已连接数量 | 显示已使用数量和套餐上限 |
| 字段 | 账号身份 | 平台、头像、名称、用户名 |
| 字段 | 连接状态 | 已连接 / 需要重连 / 需要处理 / 已断开 |
| 字段 | 可用功能 | 发布 / 排期 / 数据洞察 / 自动发布 |
| 字段 | 最近更新 | 显示最近一次检查时间 |
| 按钮 | `添加账号` | 选择平台后开始连接 |
| 按钮 | `刷新` | 更新账号和可用功能 |
| 按钮 | `重新连接` | 连接或权限异常时显示 |
| 按钮 | `移除` | 确认后解除连接 |

### 8.2 业务规则

1. 账号和必要权限确认成功后，才能显示“已连接”。
2. Instagram 不得默认显示“自动发布”。
3. 某项能力不可用时，原位说明原因和处理方法。
4. Studio 只负责选择账号；添加、重连和移除统一回到设置页面。

## 9. 数据洞察

数据洞察作为独立入口，放在数据分析分组。本期包括总览、内容列表、内容详情、问题诊断和改进建议。

### 9.1 字段与按钮

| 类型 | 名称 | 规则 |
|---|---|---|
| 筛选 | 日期范围 | 7 天 / 30 天 / 90 天 / 自定义 |
| 筛选 | 平台 | 全部 / Pinterest / Instagram / Facebook |
| 筛选 | 账号 | 只显示当前用户已连接的账号 |
| 筛选 | 内容状态 | 已发布 / 部分成功 / 失败 |
| 搜索 | 搜索内容 | 按标题、网址或画板搜索 |
| 按钮 | `对比上一周期` | 对比相同长度的上一周期 |
| 按钮 | `查看内容详情` | 查看各平台原始数据 |
| 按钮 | `根据建议创建内容` | 创建新的内容草稿 |
| 按钮 | `刷新` | 更新数据并显示更新时间 |

### 9.2 业务规则

1. 不把不同平台的曝光、观看或播放数据相加成一个总数。
2. 未连接、无权限、没有更新、不支持和真实为 0 必须分别显示。
3. 平台表现使用该平台自己的历史数据进行比较。
4. 数据不足时只展示原始结果，不给出确定性结论。
5. 改进建议使用“保持 / 修改 / 测试”，并可带着建议创建新草稿。

## 10. 固定预览入口

### 10.1 访问方式

| 环境 | 用户看到的登录方式 |
|---|---|
| 正式环境 | VibePin 登录 |
| 固定预览环境 | VibePin 登录，不出现 Vercel 登录 |
| 内部测试链接 | 仅供内部测试使用 |

### 10.2 业务规则

1. 固定预览链接为 `preview.vibepin.co`。
2. 没有登录 VibePin 时，显示 VibePin 自己的登录页。
3. 登录成功后返回用户原本打开的 Studio 页面。
4. 每次更新预览后，都要从全新浏览器检查访问结果。
5. 出现 Vercel 登录页的预览版本不得交付验收。

## 11. 本期验收清单

1. 大屏显示 3 至 4 列内容卡，手机显示 1 列。
2. “用 AI 创建”和图片卡 AI 入口使用同一套功能。
3. 输入网址后可确认摘要、图片并生成内容。
4. 用户修改过的文案不会被 AI 自动覆盖。
5. 视频卡没有任何图片生成按钮。
6. 视频封面按钮只显示在视频主画面上。
7. 每张卡只有一个“生成文案”入口。
8. 发布账号列表始终可见且可以选择。
9. 未选择账号时，系统不会自动指定默认账号或画板。
10. 排期计划默认从今天开始显示未来 7 天。
11. 过去日期只能通过“查看过去”进入。
12. “完整打开”和“收回侧栏”只放在右上角。
13. 修改每天平均发布数量后立即重新排期。
14. 自动调整不会移动已发布或手动锁定的内容。
15. 页面不再显示“已储存到这台装置”。
16. 同一账号可跨设备查看草稿和历史，不同账号不能互相查看。
17. 固定预览链接不出现 Vercel 登录页。

## 12. 后续版本

1. 完整的数据洞察与改进建议闭环。
2. 完整计划中的拖动排期和空位创建。
3. 多平台多账号额度与迁移。
4. 更完整的视频编辑、字幕和片段选择。
5. 基于历史表现的内容测试建议，仍需用户确认后创建内容。
