# VibePin Social Accounts 与多 Pinterest Account PRD

版本：V1.1  
日期：2026-08-04  
状态：产品评审稿  
本次调整：
- Settings 不展示 Board
- 客户可见账号状态精简
- Board 只在 Create Pins、Plan 和发布流程中出现

---

# 1. 核心产品原则

1. Pinterest 并入统一的 Social accounts。
2. Settings 只管理账号连接，不管理 Board。
3. Board 只在创建、编辑、排程和发布时选择。
4. 普通客户不看到 Developer tools、Sandbox、Token、API Access Tier 等技术信息。
5. 支持同一 Workspace 连接多个 Pinterest Account。
6. 每条 Pin 明确保存目标 Pinterest Account 和 Board。
7. Scheduled Pin 的目标账号和 Board 不受默认账号变化影响。
8. Reconnect 只修复原账号，不创建新账号，不占用新额度。

# 5. 客户可见账号状态

普通客户只使用 4 个状态。

## 5.1 Connected

```text
Connected
```

含义：

账号已经连接，可以正常使用。

操作：

 Manage
 Disconnect

---

## 5.2 Needs attention

```text
Needs attention
```

含义：

账号仍然存在，但有一项问题可能影响发布。

适用于：

 暂时无法同步账号信息
 部分权限需要更新
 平台暂时返回异常
 非立即阻断的问题

文案：

```text
There’s an issue with this account that may affect publishing.
```

操作根据实际问题显示其中一个：

 Try again
 Update permissions
 Contact support

不同时展示多个技术原因。

---

## 5.3 Needs reconnect

```text
Needs reconnect
```

含义：

Token 已失效、授权被撤销或自动刷新失败，需要重新授权。

文案：

```text
Reconnect this account to continue publishing.
Your drafts and scheduled content will stay safe.
```

操作：

 Reconnect
 Remove account

---

## 5.4 Disconnected

```text
Disconnected
```

含义：

账号记录仍保留，但目前未连接，不能发布。

文案：

```text
This account is not currently connected.
```

操作：

 Reconnect
 Remove account

# 6. 状态显示规则

一个账号一次只显示一个客户状态。

优先级：

```text
Needs reconnect
→ Needs attention
→ Disconnected
→ Connected
```

不得同时出现：

 Connected
 Limited Access
 Boards Enabled
 Pin publishing Enabled
 Could not sync boards
 Standard publishing access

这类互相冲突的多状态组合。

内部可以保存更细的状态，但客户端必须归一成以上 4 种。

# 9. 多 Pinterest Account

## 9.1 连接规则

 每个独立 Pinterest Account 分别 OAuth
 每个账号创建一条独立 Social Account
 同一账号重复连接时不创建第二条记录
 Add account 占用一个套餐额度
 Reconnect 不占用新额度
 新连接账号不自动成为默认账号

---

## 9.2 Add account

```text
Add account
→ Select platform
→ Check plan limit
→ Pinterest OAuth
→ Verify callback
→ Get authorized account identity
→ Check duplicate
→ Save account
→ Show success
```

成功：

```text
Pinterest connected

@account-name is ready to use.

[Use this account]
[Manage account]
```

达到额度：

```text
You’ve reached your social account limit.

Your current plan includes 5 connected accounts.

[Upgrade]
[Manage accounts]
```

重复连接：

```text
This Pinterest account is already connected.

[View account]
```

# 10. Reconnect

Reconnect 必须：

 继续使用原 social_account_id
 更新原 credential
 不新增账号
 不占用额度
 不改变已有 Draft 和 Scheduled Pin
 验证 OAuth 返回的账号是否为原账号

如果用户登录了另一个账号：

```text
This isn’t the original Pinterest account.

You signed in as @newaccount.
This connection belongs to @oldaccount.

[Sign in to @oldaccount]
[Add @newaccount as a new account]
```

禁止直接覆盖。

# 11. Disconnect 与 Remove

## Disconnect

 停止当前授权
 保留账号记录
 保留 Draft
 保留 Scheduled Pins
 保留历史发布记录
 继续占用额度
 相关排程显示 Needs reconnect

## Remove

 从 Workspace 中移除账号
 释放额度
 删除前检查未来排程
 有未来排程时禁止直接移除

提示：

```text
This account has 14 scheduled Pins.

Choose what to do before removing it

- Keep the account
- Reassign scheduled Pins
- Cancel scheduled Pins and remove
```

# 12. Board 的产品归属

Board 不进入 Settings。

Board 只在以下位置出现：

 Create Pin
 Edit Pin
 Publish now
 Schedule
 Plan
 Smart Schedule
 Failed publish retry

关系：

```text
Pinterest Account
→ Board
```

用户先选择 Pinterest Account，再选择该账号下的 Board。

Settings 不需要展示、编辑或同步 Board。

后台仍可同步 Board 数据，但同步结果只在用户需要选择 Board 时使用。

```text

@account-a

```

不在确认弹窗里维护另一套目标选择状态。

## Schedule

Scheduled Pin 固定保存：

 target_social_account_id
 target_destination_id

 destination snapshot
 scheduled_at

# 15. 默认账号

支持 Workspace default account。

规则：

 仅 OwnerAdmin 设置
 新连接账号不自动设为默认
 修改默认账号不影响已有 Draft
 修改默认账号不影响已排程内容
 删除默认账号前要求选择替代账号或清除默认

不在 Settings 设置 Default Board。

Default Board 是否需要，后续在发布体验中单独评估。

# 20. 验收标准

1. Settings 不再有独立 Pinterest 一级入口。
2. Pinterest 账号统一显示在 Social accounts。
3. Settings 中不显示 Board。
4. Account 卡片不显示 Board 数量。
5. Account details 不显示 Default Board。
6. 普通用户不看到 Developer tools。
7. 普通用户不看到 Sandbox、Token 或 Access Tier。
8. 一个账号一次只显示一个状态。
9. 客户状态仅包含：

    Connected
    Needs attention
    Needs reconnect
    Disconnected
10. 可以连接多个 Pinterest Account。
11. Reconnect 不创建新账号。
12. Reconnect 不占用新额度。
13. 登录错误账号时不会覆盖原账号。
14. CreateEdit 中先选 Account，再选 Board。
15. 改 Account 会清除原 Board。
16. Schedule 固定保存 Account 和 Board。
17. 修改默认账号不影响已排程内容。
18. Plan 可以按 Account 筛选。
19. Retry 使用原 Account 和 Board。
20. Remove 前必须处理未来排程。
