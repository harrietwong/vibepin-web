## 5. 实测脚本与证据
优先同一组内置示例商品或用户已明确授权的测试素材，对不同产品执行：
发现/搜索 → 筛选收藏参考 → 导入商品或链接 → 自动推荐与手动选择方向 → 配置品牌/平台/格式 → 生成与等待 → 结果比较 → 局部修改/重新生成 → 多尺寸/视频 → 导出/草稿/排期入口 → 历史恢复。
重点：保存商品身份、参考来源、文案、目的链接与联盟参数；首次设置与重复使用；返回、刷新、换标签、部分成功、失败重试、扣费提示；点击数与必须填写字段数。不得人为制造付费失败、攻击或突破限制。
每个功能标记：实测完成 / 界面入口可见 / 官方文档说明 / 厂商主张 / 未验证。不把广告在投、投放时长、收藏或观看量写成真实销量/转化率。
同一证据记录日期、URL、登录/免费/试用状态、真实步骤、观察结果、限制、截图路径、可借鉴点和VibePin验收建议。
深度竞品每个尽量5–8张关键界面截图；核心流程确有墙时用实际截图说明，不能填充营销截图凑数。总目标≥30张有效产品截图，受限则如实报告完成数和缺口。
截图来自真实渲染页面，必须本地落盘、实际打开检查非空/非黑/无重复，报告嵌图可打开；裁剪/打码只能明确标注，不重绘或伪造产品截图。屏蔽账号凭据/验证码等敏感信息。图片来源文件和捕获日期分清，新截图与旧截图不能冒称同日实测。
